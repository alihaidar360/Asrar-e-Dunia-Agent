Ye folder KHALI HAI - tumhe khud ek music file yahan daalni hai.

ZAROORI STEP:
1. Koi bhi royalty-free/copyright-free background music file download karo
   - YouTube Audio Library (studio.youtube.com -> Audio Library) - 100% free, sabse safe
   - Pixabay Music (pixabay.com/music) - free
   - Free Music Archive (freemusicarchive.org) - free (license check karo)

2. Us file ka naam badal kar rakho: default_background.mp3

3. Isi folder (assets/music/) mein rakh do

Suggestion: koi soft, cinematic/mysterious instrumental track chuno jo history
documentary jaisa feel de (bina lyrics ke, taake narration ke sath clash na ho).

Agar tumhe alag-alag mood ke liye multiple tracks chahiye (jaise tense scenes ke
liye alag, calm scenes ke liye alag), unhe bhi isi folder mein rakh sakte ho aur
video_assembler.py mein logic add kar sakte hain baad mein.
